### MLOps with Hands-On Machine Learning with Scikit-Learn and PyTorch 

![](https://www.oreilly.com/covers/urn:orm:book:9798341607972/400w/)
[ref:https://www.oreilly.com/library/view/hands-on-machine-learning/9798341607972/]

This repository translates the practice of what Machine Learning and Deep Learning are, with MLOps implementations, into coding practice and best practices. At the same time, it serves as a theoretical review of what Aurélien Géron proposes in his new book, Hands-On Machine Learning with Scikit-Learn and PyTorch (2025).

One of the fundamental aspects when addressing these proposals or solutions is the application of technologies like Weights & Biases (W&B) for model experimentation tracking and MLflow for the model lifecycle (as the cases are static, the focus will be on how to assign a definitive model to pass to production). Furthermore, the use and design of APIs is covered to provide a well-structured and efficient inference framework. On the CI/CD side, solutions like Docker and its respective deployment in GitHub Actions will be implemented.
